# 02 — 影像与声音的决定

## 影像

**一个前提**：图版是 2:3 竖幅（1024×1536），成片是 16:9。
横向取窗几乎没有余量——这是上一场（AME-1435 泰州漫剧）用血换来的：
9:16 竖屏从 2:3 取窗时，再想横移就会拍到工具水印或画外。

所以本片的运镜只有三种，全部是"不横移"的：

| 运镜 | 用在哪 | 为什么 |
| --- | --- | --- |
| push（缓慢推进 1.00→1.10/1.14） | 大部分有脸的镜头 | 推近＝听进去。观众被按向那张脸。 |
| pan（1.14 倍窗内的小幅平移，纵向为主） | 板、巷、街 | 只在有横向余量的图上用，位移 ≤ 0.10 画幅 |
| static（1.02–1.06 定窗） | 门口、天亮 | 让人物自己动，镜头不动 |

**黑白**：全片去色，只保留一处红——门上倒贴的红纸（S16）。红色是"到没到"的坐标，
不是装饰。`verify.py` 用两件事锁住它：全片 R/G 中位差 ≤ 6；除 S16 外红色像素 < 400。

**颗粒**：12 张预乘好的噪点层循环使用，加在 Y 上（`ImageChops.add(scale=1, offset=-128)`）。
颗粒解决两个问题：① 掩盖 1024→1920 的放大软；② 让静态图版"活着"（相邻帧必须有差）。
代价是码率：CRF 18 下全片会到 30 Mbps 以上，所以交付版用 CRF 21，并保留一份 CRF 18 作对照。

**曝光呼吸**：有灯的镜头加 ±2.2% 的亮度抖动（两个不同频率的正弦叠加），避免"死灯"。

**底部渐暗**：下 28% 按 1.6 次幂压到 0.58。字幕在任何画面上都读得出来，同时像一层印片。

## 字幕

- 只出英文（评委会语言），中文只在片名与片尾。
- 42 px Noto Sans SC 子集，白 240 加 2 px 黑影；最多 56 字符一行。
- **字幕不由人写第二份**：全部由 `story.py` 的 `LINES[].en` 与 `CARDS` 推出来，
  srt 与烧进画面的字幕同一个函数（`render.py:subtitle_ranges` / `make_srt.py:build`）。

## 声音

**一个音贯穿全片：450 Hz 拨号音。**
它是全片的主音（tonic），也是片名的意思——"总机"在英文里就是接线员接起时说的
"number, please"。450 Hz 在片中出现三次：S01 的继电器之后、S22 的清晨、片尾。

| 层 | 做法 |
| --- | --- |
| 音乐 | 「口琴」四音动机（0, -3, -5, -3 半音）+ 低频弦垫；口琴用带限噪声激励 + 共振峰滤波合成，不用采样 |
| 音效 | 继电器、塞绳插入、铃、椅子、纸、章、水壶、上弦、雪地脚步、敲门、门闩、耳机挂上/取下、拨号音——逐个用 numpy 合成，按 `story.py:SFX` 摆位 |
| 配音 | edge-tts 五个音色（秀兰/小孩/老周/建国/他妈），逐句量长度，超出留给它的空档直接报错退出 |
| 混音 | 人声侧链压音乐 70%，母带 tanh 软限幅后归一 |

**不取任何外部音频**。全片每一个声音都是代码算出来的，除了 TTS。

## 三条自审过的否决

1. **不加旁白**（"那年冬天……"）——一加就变成解说片；观众应该从"割接"这个词里自己听出来。
2. **不配大提琴**——黑白 + 雪 + 大提琴是最省事也最俗的组合。口琴更土、更对。
3. **片尾不做照片蒙太奇**——本片没有真实照片可用（也不该伪造）。片尾只留字与拨号音。
