# 06 — 闸 D 的尺子（这一场终于有往届了）

前十四场里，多数是"首届"，闸 D 只能拿同题版本盲排替代。**这一场不一样**：
Artefact AIFF 已经办到第三屆，第二屆（2025，主题 *(Dis)play*）留下了完整的竞赛档案。

## 可用的尺子

- 第二屆投稿 **201 部**，**14 部**进竞赛，前 20 名在 mk2 Curiosity 频道播两周。
- 官方画廊：<https://2025.artefact-ai-film-festival.com/gallery>
- 评委席：Cédric Klapisch（主席）、Paul Trillo、Elisha Karmitz、Bruno Patino、Ana Girardot、
  Junie Lau（2024 得主）、Jeremy Boxer、Raphaël Frydman（2024 得主）、Anna Apter、Pierre Zandrowicz。

**这意味着判据可以是"能不能进 20/201"，而不是"我喜不喜欢"。** 本片的闸 D 就按这个判。

结论先写在这里：**(Dis)Connection 这个题在 AI 短片池里已经非常拥挤**，而且拥挤的方向是
"关系断裂 / 亲人不在 / 屏幕隔离"。所以本片不能靠"孤独"取胜——它必须靠**具体**：
一个具体的工种（话务员）、一个具体的动作（把口信走到门口）、一个具体的历史时刻（割接前夜）。

## 本片拿什么去比

1. **可复述性**：一句话能讲完（线断了，人走过去），而且听完想看那个动作怎么拍。
2. **形式上的一个硬约束**：全片黑白，唯一彩色是门上那张红纸。这在 201 部里是可辨识的。
3. **不做的事**：不出现机器人、不出现未来城市、不出现 AI 与人对话——这三样在池子里最挤。

## 闸 D 的问法（对评委）

- 甲（盲）：只给六帧，问"讲了什么 / 哪张读不懂 / 想不想点开"。
- 乙（选片人）：给片名 + 一句话 + 六帧 + 规格，问"进前 20 / 只在长名单 / 不进"，并说
  "和另外 200 部的差别在哪"。

**判定线**：两人都判"进"→ 过；一人"进"一人"长名单"→ 条件性通过；两人都判"不进"→ 未过线。
两人**独立指到同一处**缺点 → 必须改；只有一人指到 → 记录不改。
