# 01 — 剧本与结构

## 一句话

割接前夜，话务员秀兰接到一通"已经打不通"的电话；线路没了，她把口信走街送到那户人家门口。

## 台词的规矩

1. **不解释时代**。所有背景信息交给声音与器物：继电器的响、塞绳的垂、"割接"这两个字。
2. **话务员的句子是工作语言**："要哪里？""稍等。""我给你接。"——她的职业性就是她的性格。
3. **全片最重的一句是最短的**：老周说"拆。"；秀兰说"好。"
4. 英文字幕是给评委的，不是给角色的；中文口语不为了好翻译而改。

## 关键决定（定过的，不再翻）

- **不让建国出现**。他只存在于声音里；一旦给脸，片子就变成"母子团聚"。
- **不拍拆机器**。板子一直是完整的，只是灯灭了——比拆掉更难受。
- **结尾不给"传承"**。她戴上耳机说"喂，总机"，拨号音起来，画面黑。没有下一个人在等她。
