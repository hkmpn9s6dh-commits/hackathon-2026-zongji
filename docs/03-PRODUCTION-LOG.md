# 03 — Production Log / 制作记录

官方要求：**前制、制作、后制三个阶段，每个阶段至少使用一种生成式 AI**。
本表逐阶段列出工具、用途、输入、输出与可核对的证据。证据都能在本仓库里查到。

---

## 阶段一 · 前制（Pre-production）

| 项 | 内容 |
| --- | --- |
| 生成式 AI | 大语言模型（CodeBuddy / WorkBuddy 会话中的生成式语言模型，Claude 系） |
| 用途 | 剧本起草与迭代、人物小传、对白打磨、分镜表（23 镜）、英文字幕翻译 |
| 输入 | 赛事规则与本片命题（人工给定）；人物与时代设定（人工给定：1987 年冬、北方县城、人工台退网） |
| 输出 | `story.py`（唯一事实来源：镜头表 / 台词 / 说明卡 / 音效表 / 片尾字幕）、`docs/01-STORY.md` |
| 人工做了什么 | 定命题与人物、否掉"机器人学会爱"类方向、逐句改台词、定 303 秒的节奏、决定"建国不给脸" |
| 证据 | `story.py` 是全部下游素材的唯一来源；改一个字，字幕、srt、配音、分镜表全部跟着变（`verify.py` §二 会核对注释里的片长与实测片长一致） |

> 说明：本片编剧署名为张一。语言模型承担的是起草与扩写，剧本的取舍与最终文字由作者定稿。

## 阶段二 · 制作（Production）

| 项 | 内容 |
| --- | --- |
| 生成式 AI | **ImageGen**（WorkBuddy 内置的生成式图像模型） |
| 用途 | 生成 21 张 1024×1536 黑白图版（35mm 胶片剧照质感），覆盖 23 个镜头（个别镜头复用同一图版的另一取窗） |
| 输入 | 逐镜的英文提示词（人物/器物/光线/胶片质感），角色一致性靠"同一人物描述 + 同一构图语法"重复提交 |
| 输出 | `plates/raw/*.png` 原件（保留，带 C2PA 类 AIGC 元数据）→ `plates/*.png` 处理后图版（2400×1350） |
| 人工做了什么 | 写提示词、逐张筛选（废片留在 `plates/raw/` 里，可对照）、决定哪张进片、哪张不用 |
| 证据 | 每张 `plates/raw/*.png` 内嵌 **TC260 AIGC 元数据**（`ContentProducer` / `ProduceID` / SM2 签名），可直接读出"这是生成图"；`plates.py` 只做裁切、去水印、统一影调，不重绘 |

处理链（`scripts/plates.py`）：去工具水印（右下角中值滤波，**不裁**）→ 取 16:9 窗 →
统一黑白色调 → 只保留一处红（S16 的红纸）。

## 阶段三 · 后制（Post-production）

| 子项 | 生成式 AI | 工具 | 输入 → 输出 |
| --- | --- | --- | --- |
| 配音（voice generation） | **是** | edge-tts（神经网络 TTS，5 个音色） | `story.py:LINES` → 30 条配音 → `build/audio.wav` 的对白层 |
| 音乐与音效 | 否（程序合成） | Python + numpy，全部从正弦/噪声/滤波合成 | `story.py:SFX` / `MUSIC` → 器乐层与环境层 |
| 剪辑与运镜 | 否（程序化） | `scripts/render.py`（Pillow 逐帧 + ffmpeg 编码） | 图版 + 镜头表 → 7272 帧 → 5 段 mp4 → 拼接 |
| 叠加与特效 | 否（程序化） | 颗粒层、雪粒子（三层视差）、呼吸/蒸汽、灯闪、**灯灭（dying）** | 见 `render.py` 的 `ov` 分支 |
| 调色 | 否（程序化） | 黑白化、底部渐暗、单片红 | 见 `render.py` / `plates.py` |
| 混音 | 否（程序化） | 人声侧链压音乐、tanh 软限幅、峰值归一 | `scripts/audio.py` |
| 字幕 | 否 | 由 `story.py` 推出，烧入 + 另出 srt | `render.py:subtitle_ranges` / `make_srt.py` |

**后制阶段的生成式 AI 用的是配音（voice generation）**，这是官方列举的后制项之一。

---

## 一次成片是怎么造出来的

```
story.py  ──┬─→ plates.py  ← plates/raw/*.png（ImageGen）
            ├─→ audio.py   ← edge-tts + numpy 合成 ─→ build/audio.wav
            ├─→ render.py  ─→ 分段 mp4 ─┐
            └─→ make_srt.py ─→ out/*.srt │
                                          └→ build_film.py 拼接+混流 ─→ out/zongji.mp4
```

一条命令：`bash verify.sh`（clone 里也能跑）。
